# 局部模板片段

ElfUI beta.12 提供两种只在当前文件生效的编译期模板片段：

- `fragment\`...\``：一次性匿名片段，适合直接插入模板，或配合数组 `map()`。
- `defineFragment<Props>()`：有名称、有 props 类型的局部片段，适合拆分较大的组件模板。

它们都不会注册 Custom Element、创建 Shadow Root 或产生独立组件生命周期。编译后，片段会透明地展开到所属 `defineHtml()` 组件中。

## `fragment`：匿名片段

`fragment` 可以直接作为模板插值：

```ts
import { defineHtml, fragment } from "@elfui/core";

export const EmptyState = defineHtml(`
  <section>
    ${fragment`
      <strong>暂无数据</strong>
      <span>请稍后重试</span>
    `}
  </section>
`);
```

也可以使用接近 React 的数组 `map()` 写法：

```ts
interface Item {
  id: number;
  label: string;
}

const items: Item[] = [
  { id: 1, label: "Alpha" },
  { id: 2, label: "Beta" },
];

export const ItemList = defineHtml(`
  <ul>
    ${items.map(
      (item, index) => fragment`
        <li>
          <span>${index + 1}</span>
          <strong>${item.label}</strong>
        </li>
      `,
    )}
  </ul>
`);
```

beta.12 支持把 `fragment` 作为直接插值，或作为 `array.map()` 回调的直接返回值。模板必须能够被编译器静态分析，不能在运行时动态拼接后再传入。

## `fragment` 与 `v-for`

两者都是列表表达方式，但定位不同：

| 场景                                          | 推荐写法   |
| --------------------------------------------- | ---------- |
| 简单列表、需要明确 `:key`、会频繁重排         | `v-for`    |
| 希望使用 TypeScript `map()` 思维组织模板      | `fragment` |
| 每个列表项需要返回多个同级节点                | `fragment` |
| 需要在模板中直接使用 `v-if`、`v-for` 局部变量 | `v-for`    |

```ts
// 推荐：需要稳定 key 的可重排列表
export const KeyedList = defineHtml(`
  <article v-for="item in items" :key="item.id">
    {{ item.label }}
  </article>
`);
```

beta.12 的 `fragment` 数组渲染使用数组索引维护片段身份。因此它可以作为许多只追加、整体替换或展示型列表的 `v-for` 替代写法，但不是带稳定 key 的 `v-for` 的完全替代品。

## `defineFragment`：命名片段

当匿名模板变长或会被重复使用时，使用 `defineFragment`：

```ts
import { defineFragment, defineHtml } from "@elfui/core";

interface SummaryItem {
  id: number;
  label: string;
  value: number;
}

interface SummaryCardProps {
  item: SummaryItem;
  compact?: boolean;
}

const SummaryCard = defineFragment<SummaryCardProps>(
  ({ item, compact = false }) => `
    <article class="summary-card" :class=${compact ? "is-compact" : ""}>
      <span>${item.label}</span>
      <strong>${item.value}</strong>
    </article>
  `,
);

export const Dashboard = defineHtml(`
  <section class="summary-grid">
    <SummaryCard
      v-for="item in items"
      :key="item.id"
      :item="item"
      :compact=${compact}
    />
  </section>
`);
```

变量名就是模板标签名，标签属性组成只读 props 对象。推荐使用 PascalCase 变量名，让局部片段和原生 HTML 标签容易区分。

## 它不是独立组件

`defineFragment` 的作用是拆分模板，不是创建新的组件边界：

- 不能导出或跨文件注册。
- 不拥有独立的 props storage、事件系统、插槽或生命周期。
- 不创建新的样式隔离边界。
- 片段中的响应式表达式、指令、事件和清理资源属于外层组件。

需要跨文件复用、独立生命周期、Shadow DOM 或公开组件 API 时，应使用 `defineHtml()` 创建真正的 ElfUI 组件。

## 静态限制

- `defineFragment()` 必须赋值给当前文件的 `const`。
- 片段名称不能和同文件的其他局部组件或片段冲突。
- render 函数必须直接返回可静态分析的模板字符串。
- 不支持运行时动态模板或跨文件 Fragment。
- 不支持的嵌套形式会产生 `ELF_MACRO_FRAGMENT_*` 编译诊断。

完整签名参见 [Core API](/zh/API参考/elfui)。
